# 回転リングの修正

## 原因

従来のTransformControlsはY軸ハンドルを半円で描画していました。
また、クォータニオン更新後のXYZオイラー角に対してX/Zを0にする処理がありました。
Yが90度を超えると同じ姿勢を表すX/Zがπになるため、これらだけを消すと姿勢が折り返します。

## 対応

移動・拡縮は既存のTransformControlsを使用します。
回転はRotationRingで、接地基準点を中心とする水平な360度リングを表示します。
Three.jsのRaycaster/Planeでマウス位置を水平面へ投影し、前回との角度差を累積します。
±180度の境界を補正し、複数周を許可します。中心付近は角度が不定なため更新しません。
ポインター押下をカメラより先に受け取り、回転中はカメラ操作を止めます。
確定時のみ既存のドキュメント更新処理を呼び、Esc・フォーカス喪失・pointercancelでは戻します。

## 検証

`npm run test:e2e -- --grep 'H\.'` は実API・専用MySQL DBを使い、
リングのクリック、取り消し、押したまま450度の回転、保存、再読み込みを検証します。
従来の「5度以上変化」という条件では90度以降の折り返しを検出できなかったため、
450度という操作結果を照合する条件へ強化しました。
成功時の画像とJSONは `artifacts/e2e/garden-rotation-*` に出力します。
