# Greenlyオーバーレイの停止対象

## Context

オーバーレイのインスタンスが保持する起動プロセスだけでは、`start.bat`からの既存起動や、オーバーレイ再起動後の停止・再起動ができなかった。

## Decision

設定されたプロジェクトの絶対パスとプロセスの実行コマンドを照合する。対象はそのフォルダーの起動スクリプト、Vite、`backend`を明示したuvプロセスとその子プロセス。停止直前にもPID、生成時刻、コマンドを再確認する。オーバーレイ自身の起動分は停止シグナルを先に送る。停止後は終了中のプロセスを再確認し、再起動前に対象の消失を確認する。

## Alternatives

ポート番号だけで終了する方式はプロジェクトを識別できない。インスタンス内の起動記録だけに依存する方式は、既存起動とオーバーレイを開き直した場合を操作できない。

## Consequences

同じプロジェクトフォルダーで複数起動したセッションは停止時にすべて終了する。MySQLサービスは対象外。手動起動など、照合対象の起動形式を使わないプロセスは対象外。ブラウザのタブは閉じない。実画面の停止・再起動・オーバーレイ再起動後の操作結果を`sysover-ray2/verification/ui-control-report.json`に記録する。
